# Tasks — to-dos

This is where you keep open tasks. The system **doesn't prescribe** how: a simple markdown list in this folder, one file per project, or an external tool (Jira, Todoist, Notion) — whatever suits you.

What matters: there should be **one** place from which `/starter-kit-en:start-session` and Adam (`starter-kit-en:status`) can read the open items. If you use an external tool, note here in one line where your tasks live, so the main agent knows where to look.

## Simple start (markdown)

Create a `tasks.md` containing:

```
## Open
- [ ] Task description (what the goal is, what "done" means)
- [ ] …

## Done
- [x] Completed task
```

A task should be **understandable on its own**: what it is, why, and when it counts as done — not a cryptic label.
