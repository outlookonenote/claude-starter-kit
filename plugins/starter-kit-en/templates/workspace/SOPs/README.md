# SOPs — recorded rules

An SOP (Standard Operating Procedure) is a distilled, numbered rule: something we decided once and that should now happen on its own. The main agent and the teammates refer to them so the same thing doesn't have to be explained again and again.

## Format

Every SOP:

```
# SOP-NN: Title
**Scope:** who it applies to
---
## Rule           — what to do (concrete, testable)
## Why            — 1-2 sentences, so it doesn't have to be re-derived later
## How to apply
## Prohibitions   — (optional) explicit "don't"
```

## New SOP

A new rule is born under **SOP-00 (self-learning)**: the main agent offers to record it, the owner approves, and it is created with the next free number (`SOP-05`, `SOP-06`, …). Don't create an SOP without approval, and don't duplicate an existing one — extend it instead.
