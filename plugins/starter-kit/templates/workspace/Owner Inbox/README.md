# Owner Inbox — ami rád vár

Ide kerül, aminél **döntés vagy a te véleményed** kell, mielőtt tovább lehet lépni. A fő-agent és a kollégák ide teszik azt a kimenetet, ami nem folytatható emberi döntés nélkül: választási helyzet, jóváhagyásra váró javaslat, kérdés hozzád.

Ha egy munkánál nincs eldöntendő kérdés, ide nem kerül semmi — ez nem naplózó mappa, hanem a te döntési sorod.
