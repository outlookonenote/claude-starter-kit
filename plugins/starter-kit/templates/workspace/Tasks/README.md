# Tasks — feladatok

Itt tartod a nyitott feladatokat. A rendszer **nem köti meg**, hogyan: lehet egyszerű markdown-lista ebben a mappában, egy fájl projektenként, vagy egy külső eszköz (Jira, Todoist, Notion) — ahogy neked kényelmes.

A lényeg: legyen **egy** hely, ahonnan a `/starter-kit:start-session` és Ádám (`starter-kit:status`) ki tudja olvasni a nyitott dolgokat. Ha külső eszközt használsz, írd le itt egy sorban, hol vannak a feladataid, hogy a fő-agent tudja, hova nézzen.

## Egyszerű indulás (markdown)

Készíts egy `feladatok.md`-t, benne:

```
## Nyitott
- [ ] Feladat leírása (mi a cél, mi a „kész")
- [ ] …

## Kész
- [x] Elvégzett feladat
```

Egy feladat legyen **önmagában érthető**: mi a dolog, miért, és mikor számít késznek — ne kriptikus címke.
